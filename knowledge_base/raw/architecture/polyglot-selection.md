# 多语言技术选型矩阵

技术栈应由业务、团队、预算、交付期限、性能、生态、合规与运维能力共同决定。

- Python：适合 AI、数据、自动化、快速业务验证；需评估运行时性能与依赖治理。
- Java：适合大型企业系统、成熟治理和长期维护；初始工程与资源成本通常更高。
- Go：适合云原生服务、网络程序和易分发的服务端程序；复杂业务生态需逐项评估。
- C++：适合低延迟、嵌入式、硬件或高性能计算；开发、测试和安全成本较高。
- TypeScript/JavaScript：适合 Web 全栈和前端密集产品；需治理依赖与运行时版本。

MVP 默认优先模块化单体，除非独立扩缩容、组织边界、合规隔离或故障域证据足以
支持微服务。架构决策必须记录取舍，不以流行度代替约束分析。
